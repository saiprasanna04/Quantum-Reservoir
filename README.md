# Quantum Reservoir Computing for Non-Linear Dynamical Systems

## Scope
This starter project implements a reproducible **ideal quantum-circuit simulation** for one-step-ahead forecasting of a synthetic Mackey–Glass-like series. It uses PennyLane's `default.qubit` simulator and a fixed entangling circuit, followed by a classical Ridge-regression readout.

**Scientific honesty:** this is not a physical trapped-ion experiment and does not by itself establish quantum advantage. The circuit is trapped-ion-inspired at the conceptual level; replace its gate pattern with a calibrated trapped-ion Hamiltonian/model if the project requires a hardware-faithful simulation.

## Setup (Windows PowerShell)
```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python src/run_experiment.py
```
If PowerShell blocks activation, run:
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

## Outputs
- `results/results.json`: metrics and experimental configuration
- `figures/forecast_comparison.png`: actual vs predicted series
- `figures/rmse_comparison.png`: RMSE comparison

## Method
1. Generate a deterministic synthetic non-linear series.
2. Create sliding windows and split chronologically into 60% train, 20% validation, 20% test.
3. Encode the input window into fixed quantum rotations.
4. Evolve through fixed local rotations and entangling gates.
5. Measure local Pauli-X/Pauli-Z observables and pair correlations.
6. Fit a Ridge regression readout; select its regularization on validation data.
7. Compare against persistence and classical Ridge baselines.

## Reproducibility notes
- The random seed is fixed for future extensions; the current synthetic generator and ideal simulator are deterministic.
- No random shuffle is used.
- All reported metrics should be generated by running the script on the target computer.
